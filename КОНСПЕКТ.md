# Конспект: Library API

## 1. Идея приложения

Приложение построено на **FastAPI** и реализует CRUD-операции для книг:
создание, чтение списка, чтение одной записи, полное обновление и удаление.

Архитектура разделена на слои:

- `main.py` — запуск приложения и подключение роутера;
- `database.py` — движок и фабрика асинхронных сессий;
- `models/books.py` — описание таблицы SQLAlchemy;
- `schemas/books.py` — проверка входных и выходных данных;
- `repository.py` — все запросы к базе данных;
- `routers/books.py` — HTTP-логика;
- `tests/test_books.py` — проверка API.

## 8. Как проверить

1. Создать виртуальное окружение и установить зависимости из `requirements.txt`.
2. Запустить `uvicorn main:app --reload`.
3. Открыть `http://127.0.0.1:8000/docs`.
4. Выполнить `POST /books` с книгой, у которой `pages > 10`.
5. Проверить `GET`, `PUT` и `DELETE`.
6. Запустить `pytest -q`.

## 9. Примеры ошибок

- `422 Unprocessable Entity` — неверный JSON или `pages <= 10`.
- `404 Not Found` — книга с указанным ID отсутствует.
- `204 No Content` — удаление прошло успешно, тело ответа отсутствует.
